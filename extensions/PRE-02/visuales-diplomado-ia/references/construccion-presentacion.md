# Construcción de una presentación de primer nivel

## Arquitectura narrativa

Formula para cada diapositiva una frase: «al terminar esta lámina, la audiencia comprenderá…».
Si contiene dos resultados independientes, divídela. Ordena las diapositivas por dependencia
conceptual, no necesariamente por el orden del documento fuente.

Usa separadores de sección solo cuando orienten. La portada debe ser mínima. Cierra con una
síntesis accionable y coloca las fuentes completas al final o en notas, según la audiencia.

## Patrones de integración

- **Tesis + visual:** mensaje breve a un lado y visual conceptual dominante al otro.
- **Proceso editable:** pasos y conectores nativos; imagen solo como contexto si aporta valor.
- **Dato + evidencia:** cifra destacada, gráfica editable y nota de fuente.
- **Comparación:** columnas simétricas y criterios comunes; evita listas inconmensurables.
- **Caso:** contexto, decisión, evidencia y resultado, con jerarquía clara.
- **Mapa conceptual:** nodos editables si las etiquetas son importantes; ilustración generada
  solo si no compromete la precisión.
- **Escena editorial:** imagen dominante con poco texto superpuesto y contraste comprobado.

No agregues una segunda lámina únicamente para enseñar la imagen de la primera. Integra el
visual en la lámina de contenido o crea una lámina visual independiente solo si introduce,
explica o cierra una idea diferente.

## Densidad y legibilidad

- Una idea principal por diapositiva.
- Títulos breves y declarativos; subtítulo solo si agrega contexto.
- Párrafos largos van a notas o se transforman en estructura visual.
- Mantén márgenes y una retícula consistente.
- Usa contraste suficiente y tamaños legibles a distancia.
- No sacrifiques precisión para llenar espacios ni agregues adornos sin función.

## Evidencia nativa

Las tablas y gráficas derivadas de datos se mantienen editables. Incluye unidades, periodo,
base de comparación y fuente. Si se simplifica una tabla, conserva la versión completa en
notas, anexo o archivo de respaldo.

## Control final

Renderiza todas las diapositivas. Revísalas primero como mosaico para comprobar ritmo y
variedad, y después a tamaño completo para detectar recortes, desbordes, contraste, datos y
acentos. Abre el `.pptx` generado y confirma que contiene cada recurso visual planeado.

Usa un nombre nuevo y descriptivo, por ejemplo `Tema_presentacion_visual_v01.pptx`. Nunca
sobrescribas la fuente sin autorización explícita.
