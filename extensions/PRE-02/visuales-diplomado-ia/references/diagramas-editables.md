# Diagramas editables con texto integrado

## Principio rector

La diapositiva debe leerse como una sola composición. El texto forma parte del visual: vive
dentro de los elementos que expresan su función. Una ilustración sin texto colocada junto a
varios párrafos no constituye una integración visual.

## Selección de estructura

| Relación del contenido | Estructura predeterminada |
|---|---|
| Secuencia | etapas conectadas con número, encabezado y explicación |
| Decisión | puertas o nodos con condición, salida y criterio de detención |
| Componentes de un sistema | núcleo central y nodos satélite conectados |
| Clasificación | círculos o zonas diferenciadas con definición dentro |
| Comparación | dos campos equilibrados con criterios equivalentes |
| Fundamentos | pilares, columnas o capas con base común |
| Ciclo | nodos alrededor de un centro con conectores direccionales |
| Jerarquía | árbol o capas donde el tamaño expresa nivel |
| Datos | gráfica o tabla editable con conclusión breve integrada |

## Construcción de cada nodo

Cada nodo puede contener:

- un número, símbolo o acento visual;
- un encabezado de dos a seis palabras;
- una explicación de una o dos líneas;
- un dato destacado cuando sea esencial.

No dividas encabezado y explicación en objetos visualmente desconectados. El contenedor debe
tener aire interior suficiente y el texto debe permanecer legible a distancia. Si el contenido
excede dos líneas por nodo, divide la estructura o traslada el desarrollo a notas.

## Limpieza visual

- Usa una sola composición dominante por diapositiva.
- Limita la paleta a la base institucional y uno o dos acentos semánticos.
- Mantén formas, radios, grosores y espacios consistentes.
- Usa conectores rectos y breves; evita cruces.
- No conviertas todo en una cuadrícula de tarjetas idénticas.
- No agregues ilustraciones laterales que no participen en la explicación.
- Conserva título, fuente y folio fuera del diagrama.

## Comprobación

Al revisar la diapositiva, oculta mentalmente el título y pregunta si la composición todavía
comunica la idea. Si solo quedan formas decorativas y el significado depende de párrafos
externos, vuelve a diseñarla. Comprueba además que todos los elementos y textos sigan siendo
editables en PowerPoint.
